    Stealth Game Menu (MGS Geïnspireerd)

    Voor mijn freelancing project wou ik een interessante main menu maken voor een stealth game (Metal Gear Solid was een van de inspiratie). De bedoeling van de game was dat je werd gevangen genomen werd door druglords en je moest hun laboratorium verlaten door een Stiletto mes te gebruiken.

    Het particle effect bestaat uit de 3D model van de mes (Stiletto), die subtiel door het beeld beweegt om een dreigende maar rustige sfeer te creëren.
